# 11. Terminal output is English, documents and forge bodies are Korean

Date: 2026-09-23

## Status

Accepted

## Context

공개 리포의 명령줄 출력에 한국어가 섞였다. 반대로 규칙 문서·역할 계약·리뷰 본문은 한국어이고, 기계가
읽는 표지 문자열(`script/harness-format.sh`)은 역할 계약이 쓰고 스크립트가 읽는다 — 한쪽만 옮기면
파서가 조용히 빈 결과를 낸다.

검토한 대안.

- 전부 영어. 규칙 문서를 읽는 사람이 한국어 팀이다
- 전부 한국어. 명령줄 도구의 관례와 어긋나고 공개 리포에 맞지 않는다

## Decision

우리는 경계를 "터미널로 내는 출력은 영어, 파일과 forge 로 올라가는 본문은 한국어" 로 정한다. 명령·훅·
가드·스크립트의 메시지가 앞쪽이고, 규칙 문서·역할 계약·리뷰 입력·리뷰 요약·이슈 본문·기계 판독 표지·
코드 주석이 뒤쪽이다.

## Consequences

- 터미널 출력에 한글이 섞이면 회귀 테스트가 잡는다. BSD grep 에 `-P` 가 없어 python3 으로 찾는다
- 문서를 다른 언어로 옮기려면 표지 문자열과 역할 계약·양식을 같은 커밋에서 함께 고친다
- 회귀 테스트의 grep 패턴과 픽스처는 한국어로 남는다 — 그쪽이 검사 대상이다
