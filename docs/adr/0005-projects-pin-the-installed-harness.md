# 5. Projects pin the installed harness

Date: 2026-09-23

## Status

Accepted

## Context

전역 CLI(Homebrew)를 올리면 템플릿이 바뀐다. 전역이 곧 정본이면 올리는 순간 모든 프로젝트의 생성물이
조용히 바뀌고, 그 리포의 `check` 가 한꺼번에 깨진다. 프로젝트마다 "어느 버전으로 렌더했는가" 가
리포 안에 있어야 클론한 사람이 같은 결과를 얻는다.

검토한 대안.

- 전역 CLI 가 항상 렌더한다. 위와 같이 깨진다
- 버전 번호만 리포에 적고 전역이 그 버전을 고른다. 전역에 옛 버전이 없으면 렌더할 수 없다

## Decision

우리는 `harness install` 이 실행 파일과 템플릿을 대상 리포의 `.harness/` 에 복사하고 그 사본이 그
리포의 정본이게 한다. 전역 CLI 는 사본이 있으면 그쪽으로 넘긴다. 올리려면 그 리포에서 다시 `install` 한다.

## Consequences

- 사본이 리포에 커밋된다. 실행 파일의 셔뱅을 기계별 경로로 박지 않는 이유다 — 받은 사람이 돌려야 한다
- 프로젝트가 옛 사본이면 UI 가 재설치를 안내한다. 새 명령을 옛 사본이 모를 수 있다
- 하네스 소스 리포는 이 규칙의 예외다(0013) — 자기 자신의 사본을 갖지 않는다
