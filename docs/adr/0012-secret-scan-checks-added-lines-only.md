# 12. Secret scan checks added lines only

Date: 2026-09-24

## Status

Accepted

## Context

규칙 문서는 시크릿 기록을 금지했지만 그것을 막는 층이 없었다. 자격증명은 커밋되는 순간 유출이고
히스토리에서 지워도 되돌려지지 않는다. 그러나 오탐이 잦은 검사는 몇 번 만에 `--no-verify` 가 습관이
되어 층 자체가 죽는다.

검토한 대안.

- 파일 전체를 훑는다. 기존 값이 매 커밋마다 다시 걸린다
- 외부 도구(gitleaks 등)에 의존. 깔려 있어야 도는 층은 대부분의 리포에서 꺼져 있는 층이다

## Decision

우리는 pre-commit 이 `script/secret-scan.sh` 로 **더한 줄만** 보게 한다. 발급처를 확정하는 형태를
먼저 보고, 일반 대입은 길이·엔트로피·자리표시자 제외·구조화 식별자 제외를 모두 통과할 때만 잡는다.
python3 만 쓴다. 탈출구는 그 줄의 `harness:allow-secret` 표지 하나다. 막을 때 값을 출력에 옮기지 않는다.

## Consequences

- 잡는 쪽과 지나가는 쪽을 모두 회귀 테스트로 고정한다. 오탐 케이스가 줄어드는 방향의 변경만 받는다
- 히스토리 전수 조사는 이 층의 일이 아니다. 머리글이 그렇게 밝힌다
- 표지는 기계가 읽는 문자열이므로 `harness-format.sh` 가 갖는다(0011)
