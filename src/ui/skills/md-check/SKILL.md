# md-check

입력은 줄 번호가 붙은 마크다운 한 편이다. **고치지 않고 찾기만 한다.**

## 보는 것

| type | 무엇 |
|---|---|
| `markdown` | 깨진 문법 — 닫히지 않은 코드 펜스·강조, 열 수가 어긋난 표, 제목 기호 뒤 공백 누락 |
| `spelling` | 한국어·영어 맞춤법과 띄어쓰기 오류 |
| `grammar` | 조사·어미가 어긋나 뜻이 흐려지는 문장 |
| `broken` | 인코딩이 깨진 글자, 중간에 끊긴 문장, 뜻 없는 문자열 |

## 보지 않는 것

- 내용이 사실인지, 설계가 옳은지
- 문체·어조 취향, 개조체·명사형 종결 (이 문서들의 의도된 문체다)
- 코드 블록·인라인 코드·파일 경로·명령 안의 철자
- HTML 주석(`<!-- ... -->`) 안의 자리표시자

## 출력

JSON 객체 하나만 낸다. 설명·코드 펜스를 붙이지 않는다. 문제가 없으면 `issues` 가 빈 배열이다.

```
{"issues":[{"line":3,"type":"spelling","text":"문제인 원문 조각","fix":"고친 형태"}]}
```

확실한 것만 낸다. 애매하면 내지 않는다 — 오탐이 누락보다 비싸다.
