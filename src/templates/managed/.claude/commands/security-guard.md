> **명시 호출 전용.** 보안 판단은 사람이 받아야 하는 결과라 자동 위임하지 않는다.

**역할 계약 정본은 `.ai/templates/security-guard.md` 다. 먼저 읽고 그대로 따른다.**
이 파일에 계약을 복사하지 않는다 — 복사본은 정본 개정을 따라가지 못한다.

대상: **$1**

`$1` 이 비어 있으면 **현재 브랜치가 통합 브랜치에 대해 갖는 변경 전체**를 대상으로 삼는다.

## 이 하네스에서의 결합

| 하는 일 | 수단 |
|---|---|
| 검토 위임 | `security-guard` 서브에이전트 — diff 를 함께 넘긴다 |
| diff 조회 (리뷰 요청 번호를 받았을 때) | `.ai/forge.md` 의 diff 조회 명령 |
| diff 조회 (번호가 없을 때) | `git diff <통합브랜치>...HEAD` |
| 등록 (사용자가 지시했을 때만) | `script/post-review.sh <번호> <본문파일> Security` |

- **diff 는 이 커맨드가 가져와 넘긴다.** 서브에이전트에 조회 도구가 없다
- **등록은 기본이 아니다.** 사용자가 "리뷰 요청에 남겨줘" 라고 지시한 턴에서만 한다
- 발견에 자격증명이 있으면 **값을 출력에도 등록 본문에도 옮기지 않는다.** 파일·줄과 무엇인지만
  적고, 폐기·재발급이 먼저라고 알린다
- 회차 라벨을 손대지 않는다. 이 커맨드는 리뷰 루프가 아니다
