
- 커밋 메시지는 `{{COMMIT_DOCS_FORM}}`. 명세와 PLAN을 한 커밋으로 묶어도 된다.
- MR은 spec 변경과 plan을 **하나로** 묶는다. 승인 왕복을 1회로 줄이기 위함.
- MR 본문은 `.ai/templates/mr.md` 항목을 전부 채운다. forge 도구의 자동 채움 옵션을 쓰지 않는다.
- **관련 이슈는 `Related to #<이슈번호>` 다. `Closes` 를 쓰지 않는다** — 이 MR 이 머지돼도
  요구사항 이슈는 열린 채로 남아야 한다. 닫는 것은 구현 MR 하나다.
- **{{step:decide}}단계에서 기각된 선택지가 있으면 MR 본문에 `## 검토한 대안` 절을 더한다.**
  선택지 / 기각 근거 / 되돌리기 비용을 **ADR 유무와 무관하게** 적는다. ADR 을 쓰는 결정이면
  그 번호를 한 줄로 덧붙인다 — MR 만 보는 사람도 기각 근거를 읽을 수 있어야 한다.
