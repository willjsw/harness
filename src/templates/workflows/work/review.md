
```bash
script/review-mr.sh <MR번호>
```

스크립트가 diff를 받아 리뷰 도구에 넘기고, 결과를 MR 댓글로 등록한 뒤 판정을 종료 코드로
돌려준다. **어느 도구가 리뷰하는지는 스크립트 상단이 정한다.**
**리뷰 대상은 그 MR 의 변경 전체**다 — 분해가 있으면 전 task 의 변경 합, 없으면 단독 task 의 변경이다.

**회차와 상한도 이 스크립트가 관리한다.** 실행할 때마다 회차 라벨을 스스로 올리고, 상한에
닿으면 리뷰를 수행하지 않는다. **절차도 세션도 라벨을 손대지 않고 회차를 세지 않는다** —
세는 쪽과 멈추는 쪽이 같으면 세지 않은 회차가 그대로 상한 밖이 된다.

| 종료 코드 | 뜻 |
|---|---|
| 0 | blocker·major 0건 — minor 만 남아도 여기다 |
| 1 | blocker·major 1건 이상 |
| 2 | 리뷰를 수행하지 못함 (도구 없음·diff 조회 실패·출력 계약 위반 = `REVIEW_VERDICT` 선언 누락 또는 `## 발견 사항` 절 누락·제목 수준 위반·회차 갱신 실패·등록 실패) |
| 3 | **상한** — 회차 상한에 닿았거나 같은 blocker·major 지적이 반복됐다 |

- 역할 계약(점검 항목·반증 절차·출력 계약)은 스크립트가 아니라 `.ai/templates/code-reviewer.md`가 갖는다.
- **판정은 발견 등급 집계로 한다.** 루프를 끝낼지는 blocker·major 건수가 정하고, minor 는 세지
  않는다. 본문 마지막 줄의 `REVIEW_VERDICT` 는 **계약 준수 여부를 보는 용도**다 — 선언이 없으면
  등록하지 않고 종료 코드 2, 선언과 집계가 다르면 집계를 따르되 그 사실을 요약에 남긴다.
  기준의 정본은 `.ai/templates/code-reviewer.md` "판정의 정본은 등급 집계다" 절이다.
- **집계는 `## 발견 사항` 절 안만 센다.** 판정이 집계인 이상 절 밖의 등급 형식 줄이 판정을 바꾸면
  안 된다. 절 제목은 수준까지 정확히 `## 발견 사항` 이고, 절은 다음 제목에서 끝난다.
  절이 없거나 제목 수준이 다르거나 절 안이 비어 있으면 선언 누락과 같이 종료 코드 2 이고,
  루프를 진행하지 않는다.
- **종료 코드 2는 "PASS"가 아니다.** 루프를 진행하지 말고 멈춘 뒤 스크립트 출력을 그대로 보고한다.
  등록에 실패해도 리뷰 본문은 표준 오류로 나오므로 유실되지 않는다.
- **리뷰 수단은 이 스크립트 하나다.** 회차를 올리고 상한에서 멈추는 곳이 여기뿐이라, 이를
  거치지 않는 리뷰 경로는 상한 없는 루프가 된다. 절차는 두 번째 경로를 두지 않는다.
  다른 도구로 리뷰해야 하면 스크립트 상단의 리뷰어 지정을 바꾼다 — 리뷰어만 바뀌고 회차·상한·
  등록은 같은 경로를 탄다. 발견을 diff 라인에 다는 **인라인 등록도 이 경로가 이미 한다.**
