# script/project/

이 프로젝트의 자동화 스크립트. **이 디렉터리는 프로젝트 것이다** — 하네스 갱신(`harness render` ·
`harness install`)이 이 안의 파일을 만들지도 덮지도 지우지도 않는다.

하네스 스크립트는 `script/` 바로 아래에 있고 표는 `script/README.md` 에 있다. 그 자리는 하네스 것이라,
프로젝트 스크립트를 `script/` 바로 아래에 두면 하네스 갱신과 겹칠 수 있다.

하네스는 이 디렉터리의 스크립트를 부르지 않는다. 검증에 넣으려면 `harness.toml` 의 `[verify]` · `[commands]` 에 적는다.
